# `<plgrnd-flow>` fixtures

Host pages for agent-driven browser QA of the self-hosted widget. Serve them with:

```sh
yarn workspace @plgrnd/embed fixtures   # http://localhost:4180
```

`scripts/serve-fixtures.mjs` serves this folder at `/` and `packages/embed/dist` at `/dist/`. It resolves these templates per request:

| Template                        | Effect                                                                                    |
| ------------------------------- | ----------------------------------------------------------------------------------------- |
| `%%FLOW:P3%%`                   | the lz-string payload of `flows.json` → `P3`                                              |
| `<!--HOST-TW4-->` + `?host=tw4` | adds `vendor/tailwind-v4-host.css`                                                        |
| `?widgets=0`                    | drops every `<plgrnd-flow>` element but keeps the scripts                                 |
| `?csp=<variant>`                | adds a `Content-Security-Policy` header: `strict-dynamic`, `tt`, `no-unsafe-inline-style` |

## Flows

`flows.json` is generated by `node packages/embed/scripts/extract-fixture-flows.mjs`:

| Id  | Flow                                                | Source                         |
| --- | --------------------------------------------------- | ------------------------------ |
| P0  | Hashing                                             | `EXAMPLE_FLOWS[0]`             |
| P2  | Balance checking                                    | `EXAMPLE_FLOWS[2]`             |
| P3  | Solana transfer                                     | `EXAMPLE_FLOWS[3]`             |
| P4  | Program execution                                   | `EXAMPLE_FLOWS[4]`             |
| P6  | Text → Encode (select pinned to `base64`) → Display | authored in the extract script |
| P7  | Invalid IDL JSON, which raises a toast at mount     | authored in the extract script |

## Host probe

`assets/host-probe.js` loads first on every page and exposes `window.__hostProbe`:

- `snapshot()` resolves to the observable host state: a SHA-256 of all same-origin CSS rules, `<html>`/`<body>` attributes and inline style, `body` children, sentinel computed styles, storage, cookies, the own-key diff of `window` and `document`, `location.href` and `history.length`.
- `state` holds the counters: mutation records outside the widgets, `error`, `unhandledrejection`, `securitypolicyviolation`, document `keydown` records with `defaultPrevented`, host shortcut hits and net-active timers.
- `own(fn)` runs a fixture-owned DOM operation without attributing its mutations to the widget.

## Vendored stylesheets

Both files in `vendor/` are generated once and committed. Tailwind CSS and `@tailwindcss/typography` are MIT-licensed (Tailwind Labs, Inc.).

- `tailwind-v3-typography.css`: Tailwind v3.4.17 with `@tailwindcss/typography` v0.5.16, the Mintlify host stack.

  ```sh
  npm i tailwindcss@3.4.17 @tailwindcss/typography@0.5.16
  # tailwind.config.cjs: { darkMode: 'class', content: ['<fixtures>/mintlify-like.html', '<fixtures>/aggressive-css.html'], plugins: [require('@tailwindcss/typography')] }
  npx tailwindcss -c tailwind.config.cjs -i in.css -o out.css   # in.css: @tailwind base; @tailwind components; @tailwind utilities;
  ```

- `tailwind-v4-host.css`: a Tailwind v4.1.15 host with preflight, the static theme and `@property` registrations.

  ```sh
  npm i @tailwindcss/cli@4.1.15 tailwindcss@4.1.15
  # in.css: @import "tailwindcss" theme(static); @source "<fixtures>"; @source inline("shadow-md ring-2 translate-x-1 rotate-3 blur-sm …");
  npx @tailwindcss/cli -i in.css -o out.css
  ```
