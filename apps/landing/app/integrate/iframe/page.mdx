# Hosted iframe

Any PLGRND flow can be embedded on another site as an interactive widget: an `<iframe>` pointed at `https://plgrnd.io/embed`, with no JavaScript required on the host page. The flow itself stays in the `#flow=` hash, and display options travel in the query string.

Embeds are stateless. Visitor edits live only inside the iframe, and reloading it (or pressing **Reset**) restores the authored flow.

The preview above is served by plgrnd.io with `accent=14f195` to match this site. Pan, zoom and edit the inputs: every node wired to an input updates.

## Snippets

Each tab embeds the same flow at 16:9 with `theme=auto`. The HTML / Markdown tab is the format that the editor's **Share → Embed** builder copies; the Mintlify and MDX tabs are the same markup written as JSX.

## URL parameters

Options travel in the query string; the flow stays in the `#flow=` hash. Default values are left out of generated URLs, colours are hex without `#`, and invalid values fall back to their defaults instead of breaking the widget. Unknown parameters, `ref` included, are ignored.

`mode=editor` is iframe-only: it adds moving, connecting, adding and deleting nodes, plus the header with the node menu. `readonly` allows only pan and zoom, and `interactive` also lets readers edit values inside nodes. The self-hosted `<plgrnd-flow>` element treats `editor` as `interactive`.
