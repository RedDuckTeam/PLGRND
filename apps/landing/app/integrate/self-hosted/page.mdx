# Self-hosted widget

`<plgrnd-flow>` renders the same widget directly in your page, without an iframe. You serve the file yourself, from your own site or bundle. At runtime the widget loads no Google Fonts, no analytics, no remote CSS and nothing from plgrnd.io. Its only requests go to the Solana RPC endpoints, and it writes no cookies and no storage. Shadow DOM keeps your site's CSS out of the widget, and the widget's CSS out of your site.

The widget ships as the npm package `@plgrnd/embed` and as versioned downloads under `https://plgrnd.io/sdk/<version>/`. Download the files once and serve them yourself. The classic script `plgrnd-flow-1.0.1.js` holds everything in one file, and `SRI.txt` in the same folder lists its `sha384-…` value for `<script integrity>`. The ESM folder `plgrnd-flow-1.0.1/` holds a 7 kB entry that loads the runtime the first time an element connects.

## Snippets

To get the snippet for your own flow, open **Share → Embed → Self-hosted** in the editor and pick HTML, MDX, Mintlify or Markdoc. The snippet carries the same flow payload and options as the iframe snippet. Load the widget once per page, then paste one element per flow.

- Invalid values fall back to the defaults, silently.
- Every attribute also exists as a camelCase property, such as `fontMono`, `rpcDevnet` or `linkRef`. Properties do not reflect to attributes, and the last write wins.
- The element fires `plgrnd:ready` after each successful (re)initialization. The event bubbles, is composed, and carries `detail.version`.
- `theme="auto"` follows your site's own toggle, live: `body[data-md-color-scheme]` (MkDocs Material), then `html[data-theme]` (Docusaurus), then a `dark` or `light` class on `<html>` (Mintlify, next-themes, Fumadocs), then `prefers-color-scheme`.
- The RPC defaults are rate-limited public endpoints, so production docs should pass their own. A key you put in an attribute is visible in your page source, so restrict it by referrer.
