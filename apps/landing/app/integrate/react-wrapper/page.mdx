# React wrapper

In a React or MDX site, wrap the hosted iframe in one vetted component. Authors then write `<PlgrndEmbed src="…" title="…" />` instead of raw iframe markup, and the sandbox, the lazy loading and the allow-list for the source URL live in a single place. The theme query can be reviewed once as well.
